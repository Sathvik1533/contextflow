## THE PROBLEM IT SOLVES

Every developer using LLMs (ChatGPT, Claude, Gemini) faces this:

You're learning, building, or debugging. You need AI help.

But first, you have to MANUALLY gather context:
- Screenshot your screen or copy-paste code from IDE
- Copy error messages from terminal
- Copy text from documentation/browser
- Copy what's on your clipboard
- Switch to ChatGPT
- Type out everything: "I'm working on X, here's my code, here's the error, here's what I tried..."
- Wait for response
- Switch back
- Repeat

**This happens 10-20 times per day. 3-5 minutes each time. 30-100 minutes wasted daily.**

The real pain isn't just copy-paste. It's the ENTIRE manual workflow of explaining context to an AI that should already know what you're looking at.

You break focus. You context-switch. You re-explain the same project 20 times.

ContextFlow eliminates ALL of this.

---

## THE SOLUTION (END PRODUCT)

ContextFlow is a macOS desktop application that automates the entire context-gathering workflow.

**One hotkey. Zero manual work. AI does everything.**

Instead of you gathering context for the AI, the AI gathers context for you.

### USER WORKFLOW (FINAL PRODUCT):
1. You're coding, learning, or debugging
2. You need AI help
3. Press **Cmd+Shift+Space** (one hotkey)
4. AI agents automatically gather EVERYTHING:
   - What's on your screen (YouTube tutorial, docs, code)
   - Open files in your IDE (the code you're working on)
   - Your clipboard (what you just copied)
   - Terminal output (errors, logs, commands)
   - Browser tabs (documentation URLs, titles)
   - Git context (current branch, recent commits, uncommitted changes)
5. AI analyzes and structures all of it
6. Complete context package → clipboard
7. Paste into ChatGPT/Claude/Gemini
8. AI understands EVERYTHING without you explaining anything

**The transformation:**
- Before: 3-5 minutes of manual gathering + explaining
- After: 2 seconds. One hotkey. Done.

**You never break focus. You never context-switch. You never re-explain.**

## TECHNICAL CHALLENGES SOLVED

### Challenge 1: Model Deprecation
**Problem:** Groq deprecated Llama 3.2 Vision models mid-development
**Solution:** Migrated to Llama 4 Scout (meta-llama/llama-4-scout-17b-16e-instruct) in 30 minutes with zero downtime
**Learning:** Built resilient API integration with fallback logic

### Challenge 2: JSON Parsing from LLM
**Problem:** Vision models sometimes return JSON wrapped in markdown fences (```json...```)
**Solution:** Regex-based fence stripping + strict schema validation
**Learning:** Never trust LLM output format, always validate and clean

### Challenge 3: Multi-Agent State Management
**Problem:** Passing data between agents without losing context
**Solution:** LangGraph StateGraph with TypedDict schema (relay race pattern)
**Learning:** Shared state is the "baton" passed between agents

### Challenge 4: Infinite Loop Bug
**Problem:** Observer fails → retries → fails → retries forever (10,007 iterations)
**Solution:** Check for errors in conditional edge: `if state.get("error"): return "END"`
**Learning:** Error handling must be explicit in conditional edges, not assumed

### Challenge 5: Multi-Window Priority
**Problem:** When both browser (ESPN cricket) and terminal (Python code) visible, Observer analyzed terminal instead of browser content
**Solution:** Added PRIORITY RULE to Observer prompt: "If browser + terminal visible → analyze browser, ignore terminal"
**Learning:** Prompt engineering solves multi-window scenarios without code changes
**Impact:** Enables proving ContextFlow works on ANY content (sports, news, tech, docs), not just technical content
