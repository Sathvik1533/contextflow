I just spent 3 hours debugging an infinite loop.

The Observer agent failed. The graph tried to retry. Failed again. Retry. Failed. Retry.

10,007 iterations before LangGraph killed it.

This is the reality of multi-agent systems. One bug = infinite loop.

But here's what I learned: **Conditional edges are everything.**

When you have 4 agents passing data to each other, you can't just say "if this fails, try again."

You need smart routing:
- If Observer confidence < 0.6 → retry (maybe screen was blurry)
- If Observer returns error → EXIT (don't loop forever)
- If user says quit → EXIT (respect user intent)

One line of code fixed it:
```python
if state.get("error"):
    return END  # Exit on error, don't retry
```
